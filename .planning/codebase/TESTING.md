## Unit / Component Tests

### Pattern
Tests use Vitest's `describe`/`it` blocks with Testing Library's `render`, `screen`, and `fireEvent`/`userEvent`:

```tsx
import { render, screen } from '@testing-library/react';
import { describe, it, expect } from 'vitest';

describe('ComponentName', () => {
  it('renders correctly', () => {
    render(<ComponentName />);
    expect(screen.getByText('...')).toBeInTheDocument();
  });
});
```

### Test Utilities
- `tests/testUtils.tsx` — Shared test helpers
- `tests/wizard/helpers.ts` — Wizard-specific test utilities
- `vitest.setup.ts` — Global test setup

### Coverage
- Individual wizard steps have dedicated test files
- Core utilities have tests (`utils.test.ts`, `importExport.test.ts`)
- Component tests for UI primitives (`Button.test.tsx`, `Card.test.tsx`)
- Hook tests (`useAutoSave.test.ts`, `useFormValidation.test.ts`)
- No coverage thresholds configured

### Running Tests
```bash
npm test              # vitest run (single pass)
npm run test:watch    # vitest (watch mode)
```
