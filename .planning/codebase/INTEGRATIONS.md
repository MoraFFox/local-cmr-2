## 1. Supabase (Primary Backend)

**Client:** `supabaseClient.ts`  
**SDK:** `@supabase/supabase-js` v2.44.4  
**Env vars:** `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`

### Services Used

| Service | Usage |
|---------|-------|
| **Auth** | Admin/technician authentication with JWT tokens. Session persistence with auto-refresh. |
| **Database (PostgreSQL)** | All CRUD operations for companies, branches, maintenance records, baristas, invitations. |
| **Storage** | Photo uploads for maintenance records (camera capture in technician portal). |
| **Edge Functions** | Serverless functions for admin recovery, user management, invite signup, Google Sheets sync. |

### Custom Fetch Wrapper
The Supabase client uses a custom `fetch` wrapper in `supabaseClient.ts`:
- 30-second request timeout with `AbortController`
- Network request logging via `utils/logger.ts`
- Error body capture for debugging

### RLS & Auth
- Row-Level Security enforced on database tables
- Edge Function `verify_jwt` configuration per function in `supabase/config.toml`
- `invite-signup` and `admin-recovery`: JWT verification disabled (public endpoints)
- `admin-users` and `sync-sheets`: JWT verification required

### PWA Caching
The service worker caches Supabase REST/auth endpoints:
- Strategy: `NetworkFirst`
- Timeout: 8 seconds
- Cache: 50 entries, 1-hour TTL

## 2. Edge Functions (Supabase)

### `invite-signup` (`supabase/functions/invite-signup/index.ts`)
- **Auth:** Public (verify_jwt: false)
- **Purpose:** Redeem invitation tokens to create new admin/technician accounts
- **Endpoint:** Supabase Functions URL

### `admin-users` (`supabase/functions/admin-users/index.ts`)
- **Auth:** JWT required (verify_jwt: true)
- **Purpose:** List and manage admin/technician users via Supabase Admin API
- **Used by:** `UserAccessManagement.tsx`, `useTechnicians.ts`

### `admin-recovery` (`supabase/functions/admin-recovery/index.ts`)
- **Auth:** Public (verify_jwt: false)
- **Purpose:** Emergency admin account recovery with a secret key
- **Used by:** `EmergencyAdminRecovery.tsx`

### `sync-sheets` (`supabase/functions/sync-sheets/index.ts`)
- **Auth:** JWT required (verify_jwt: true)
- **Purpose:** Synchronize data to Google Sheets
- **Used by:** `utils/googleSheetsSync.ts`
