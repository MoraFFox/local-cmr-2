<read_first>

</read_first>

<action>
Create `utils/dateRangeFilter.ts` with:

1. **DateRange type:**
```typescript
export interface DateRange {
  startDate?: string; // "YYYY-MM-DD" inclusive
  endDate?: string;   // "YYYY-MM-DD" inclusive
  preset?: string;    // "today" | "thisWeek" | "thisMonth" | "thisQuarter" | "thisYear" | "allTime" | "custom"
}
```

2. **filterMaintenanceByDateRange function:**
- Signature: `(records: MaintenanceRecord[], range: DateRange) => MaintenanceRecord[]`
- Filters by `maintenanceDate` between startDate/endDate (inclusive)
- Recursively filters `followUpVisits` — if a follow-up is out of range, exclude it from the parent's `followUpVisits` array
- Returns new array (no mutation of input)
- If range is null/undefined or both dates empty, returns records unchanged (All Time)

3. **getDateRangePresets function:**
- Signature: `() => Record<string, DateRange>`
- Returns presets keyed by name: allTime, today, thisWeek, thisMonth, thisQuarter, thisYear
- Each preset calculates start/end as ISO date strings relative to `new Date()`
- `allTime` returns `{ preset: "allTime" }` (no start/end — means no filter)

4. **ARABIC_PRESET_LABELS constant:**
```typescript
export const ARABIC_PRESET_LABELS: Record<string, string> = {
  allTime: "كل الفترات",
  today: "اليوم",
  thisWeek: "هذا الأسبوع",
  thisMonth: "هذا الشهر",
  thisQuarter: "هذا الربع",
  thisYear: "هذه السنة",
  custom: "فترة مخصصة",
};
```

5. **formatDateRangeLabel function:**
- Signature: `(range: DateRange) => string`
- Returns Arabic label like "يوليو ٢٠٢٦" or "١ يوليو — ١٥ يوليو ٢٠٢٦"
- Used for PDF period indicator

Import `MaintenanceRecord` from `../types`.
</action>
